# Portfolio Milestone 3

## Accessibility Improvements

- Added labels to all form fields.
- Added a fieldset and legend to group form controls.
- Added semantic HTML elements for accessibility.
- Improved color contrast to meet WCAG AA standards.
- Added required validation on all contact form fields.

## Visual Design Decisions

### Proximity

I grouped project cards together on the Projects page to visually connect related content.

### Similarity

I used consistent colors, spacing, headers, and layouts across all pages.

### Color Palette

I used a consistent blue, white, and gray color palette throughout the website.

## Accessible Form

The About page contains a contact form with labels, a fieldset, a legend, and required fields for accessibility.
